| Seed imageSlug → manifest → `<img>` | Data string selects a bundled asset |
| Clipboard API → fallback DOM | Denied API must degrade to a designed state |

| T-07-03 | Spoofing | `isLinkedInInAppBrowser` | mitigate | Pure string check used only to show a hint (or nothing per D7-02); no auth/authz path reads it; never read during render |
