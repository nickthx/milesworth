<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Server (page.tsx) → client island props | Session state and the user's own saved data cross into the client bundle — only the current user's rows, never another user's |
| Client → Server Actions | Balances object and slug + boolean from attacker-controllable client code |
| URL / storage / account → island state | Three balance sources compete; precedence must not let a foreign share link clobber a user's data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Spoofing | Client cannot assert identity | mitigate | `isSignedIn` is display-only; the actions re-derive the user from `await auth()`; no userId prop exists anywhere in the island |
| T-06-05 | Information disclosure | Client bundle | mitigate | New components import only `@clerk/nextjs` client components + action references; page.tsx reads through the server module, never `@/db`; tests/guest-flow-gate.test.ts runs in every verify |
| T-06-09 | Tampering (integrity) | Balance precedence | mitigate | Pure `resolveInitialBalances` with the tested account branch; account restore uses `history: "replace"` and never writes storage; share links (URL) always win |
| T-06-17 | Denial of service (hydration) | savedBalances / bookmarkedSlugs during render | mitigate | `savedBalances` consumed only in the ref-guarded mount effect; `bookmarkedSlugs` and `isSignedIn` are identical on server and client because they are server-derived props (no `useAuth()` flip) |
| T-06-03 | Tampering | saveBalances/setBookmark arguments | mitigate | Client passes the current `Balances` and a slug; the server re-validates with Zod (06-04) — the client is not trusted to filter |
| T-06-04 | Information disclosure | Error display | mitigate | Components render only `ActionState.message` (fixed neutral copy) — no thrown errors surfaced |
| T-06-SC | Tampering | npm installs | accept | No packages installed in this plan |
</threat_model>
